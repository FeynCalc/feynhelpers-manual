\section{FSADryRun}\label{fsadryrun}\index{FSADryRun}}

\texttt{FSADryRun} is an option for
\texttt{FSAPrepareMathematicaScripts} and other functions of the FIESTA
interface.

When set to \texttt{True}, no files will be written to the disk.
