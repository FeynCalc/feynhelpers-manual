\section{KiraIntegralOrdering}\label{kiraintegralordering}\index{KiraIntegralOrdering}}

\texttt{KiraIntegralOrdering} is an option for
\texttt{KiraCreateJobFile} and other functions of the Kira interface.

It specifies the value of the \texttt{integral_ordering} parameter in
the job file. The default value is \texttt{2}. This means that KIRA will
integrals with dots rather those with numerators when choosing the
master integrals.
