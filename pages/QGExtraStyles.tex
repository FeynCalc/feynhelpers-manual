\section{QGExtraStyles}\label{qgextrastyles}\index{QGExtraStyles}}

\texttt{QGExtraStyles} is an option for \texttt{QGTZFCreateFieldStyles},
which adds additional stylings to those created for Tikz-Feynman.

For example, one can use
\texttt{QGExtraStyles -> \{\allowbreak{}"every vertex/.style=\{\allowbreak{}small,\ \allowbreak{}dot\}"\}}
to add a small dot to every vertex.
