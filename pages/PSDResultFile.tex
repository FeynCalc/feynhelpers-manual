\section{PSDResultFile}\label{psdresultfile}\index{PSDResultFile}}

\texttt{PSDResultFile} is an option for \texttt{PSDCreatePythonScripts}
and other functions of the pySecDec interface.

It specifies the prefix of the file containing the result of the
pySecDec run. The default value is \texttt{numres}.
