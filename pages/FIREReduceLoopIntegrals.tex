\section{FIREReduceLoopIntegrals}\label{firereduceloopintegrals}\index{FIREReduceLoopIntegrals}}

\texttt{FIREReduceLoopIntegrals[\allowbreak{}glis,\ \allowbreak{}topos,\ \allowbreak{}path]}
performs IBP reduction of loop integral listed in \texttt{glis} from the
families given in \texttt{topos} using C++ FIRE. It returns reduction
tables obtained from FIRE.

Since all processes are started from the current Mathematica notebook,
it can be reliably used only for simple integrals and topologies.
